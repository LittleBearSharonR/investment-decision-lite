# Investment Decision Lite

一个面向个人投资者的轻量化 Codex Skill：用较少的上下文完成上市股票或 ETF 研究，并结合真实持仓给出明确的 **加仓、持有、减仓或卖出** 建议。

## 核心特点

- **先确认标的身份**：核对代码、交易所、币种及资产类型，避免同名证券、旧代码或 ETF/个股混淆。
- **结合真实持仓**：计算总成本、当前市值、浮动盈亏、收益率与仓位风险。
- **按资产选择估值方法**：分别处理盈利公司、成长股、周期股、ETF、杠杆 ETF 和新股。
- **只研究影响决策的信息**：优先财报、监管申报、公司 IR 和可靠行情，减少无效背景资料。
- **输出明确行动**：必须给出一个主建议，并说明加仓区间、减仓或卖出条件及下一次复核节点。
- **默认节省 Token**：采用单 Agent、短报告，不默认生成 DCF、图表、模拟大师点评或机构级长文。

## 适用场景

- “研究一下这只股票，现在应该加仓还是继续持有？”
- “我的成本是 50 美元、持有 20 股，需要止损吗？”
- “这个 ETF 现在贵不贵？仓位应该怎么调整？”

不适合默认生成完整行业报告、十年财务模型或多 Agent 深度投研；如确有需要，Skill 会建议升级为深度模式。

## 使用方法

将本目录放入 Codex 的 Skills 目录：

```text
~/.codex/skills/investment-decision-lite/
```

然后直接提出请求，例如：

```text
使用 investment-decision-lite 研究某上市公司（代码：XXXX）。
我的平均成本是 50 美元，持有 20 股。
根据当前价格，我应该加仓、减仓还是不动？
```

## 输出内容

默认以简短中文给出：

1. 一句话行动结论；
2. 持仓成本、市值和盈亏；
3. 商业质量、估值与主要风险；
4. 当前仓位方案和改变建议的触发条件；
5. 数据截止时间与关键来源。

## 说明

该 Skill 提供基于公开信息的投资决策支持，不保证收益，也不能替代持牌财务顾问。用户仍需结合自身资产规模、投资期限和风险承受能力作出最终决定。
